# 小红书自动登录发布工具

## 功能

- 使用真实 Chromium 浏览器模拟人工操作
- 支持登录状态保持（下次无需重新登录）
- 支持图文发布（AI生成配图）
- 支持长文发布（一键排版）

## 安装

```bash
# 安装依赖
pip install -r requirements.txt

# 安装 Playwright 浏览器
playwright install chromium
```

## 使用方法

```bash
python xhs_publisher.py
```

## 操作流程

1. **首次运行**：会启动浏览器打开小红书官网，请完成扫码/账号密码登录
2. **登录后**：输入你想发布的主题
3. **确认内容**：查看 AI 生成的内容预览，输入 y 确认
4. **选择模式**：输入 1 选择图文模式，输入 2 选择长文模式
5. **自动发布**：程序会自动完成所有发布步骤

## 图文发布流程

1. 点击发布 → 打开创作服务平台新标签页
2. 选择图文 → 选择文字配图
3. 输入正文到 editor-paragraph → 点击生成图片
4. 随机选择卡片 → 点击下一步
5. 填写标题话题 → 点击发布

## 长文发布流程

1. 点击发布 → 打开创作服务平台新标签页
2. 点击新的创作
3. 输入标题和正文
4. 点击一键排版 → 依次下一步
5. 填写话题 → 点击发布

## 注意事项

- 首次使用需要手动登录
- 登录状态会保存在 `~/.xhs-skill/` 目录下
- 浏览器以有头模式运行，方便观察操作过程
- 如登录过期，删除 `~/.xhs-skill/` 目录后重新运行即可
